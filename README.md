# Assignment-6 Triviabook
CSC 372

## Project Description 
Triviabook is an application that asks users to answer questions and tells them if they are right or wrong.
They can answer previously answered questions or they can add their own questions. It uses Node.js, Express, and PostgreSQL. 

## Technologies Used 
HTML, CSS, JavaScript, Node.js, Express.js, PostgreSQL, Neon Database. 

## API endpoints
GET endpoints: /triviabook/topics, /triviabook/topic/:topic, /triviabook/random
POST endpoints: /triviabook/answer, /triviabook/question/add
